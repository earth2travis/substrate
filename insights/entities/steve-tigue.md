# Steve Tigue

**Role:** Creator of OpenClaw (self-hosted AI agent framework) and llmstxt.org

## Key Contributions

**llmstxt.org:** A format for making websites readable by LLMs. Predates and influenced OpenClaw's development.

**OpenClaw:** Reached 250K GitHub stars. Introduced foundational concepts: local-first execution, tool-calling agent loops, skills systems (ClawHub marketplace), persistent memory, and multi-platform messaging. "The spark that lit the self-hosted AI agent revolution."

## Security Crisis

The ClawHavoc security crisis of February-March 2026 (341 malicious skills, 138 CVEs) severely damaged OpenClaw's reputation. Many users migrated to Hermes Agent. Tigue continues development with ongoing security patches.

## Legacy

OpenClaw proved that self-hosted, persistent AI agents could work and created a massive community. Hermes Agent evolved directly from OpenClaw patterns. Code inheritance includes clawdbot's incomplete-text recovery and rate limiting.

The OpenClaw story is the archetype of the self-hosted agent movement: breakthrough innovation, rapid adoption, security crisis, community fracture, and continued evolution.
