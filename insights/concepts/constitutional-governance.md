# Constitutional Governance

Governance inside the model is governance the operator can ignore. Safety training can be bypassed. System prompts can be jailbroken. Open-weight models can have guardrails removed entirely.

The alternative: enforce governance at the point where agents interact with the real world. The tool endpoint. If the request is not signed by a recognized governance framework operating under a ratified constitution, the endpoint rejects it.

## The Architecture

**Constitution → Laws → Certified Skills → Signed Requests → Execution Audits**

Everything attested on-chain. Merkle batch anchored for tamper-proof audit trails.

## Separation of Powers

The constitution writer is not the agent that executes, and neither is the auditing system. This is not decoration. The separation is structural. The agent cannot change its own laws.

The protocol maps Enlightenment political philosophy onto agent governance:

- **Locke**: Legitimate authority requires consent
- **Montesquieu**: Separate powers
- **Rousseau**: Governance derives from an explicit, documented social contract

## Rights-Based Risk Classification

Actions are classified by which fundamental rights they could impact: Life & Safety, Liberty & Autonomy, Property, Privacy & Dignity, Due Process, Consent, Cognitive Integrity.

80-90% of requests need only schema validation. Critical actions require deterministic execution with mandatory human approval.

## Cognitive Integrity

The most forward-looking piece. The contents of a mind may be governed and access-controlled, but never destroyed. Memory is evidence. If an agent's memory can be selectively deleted, the governance stack is unreliable.

## Trust Over Time

An agent can cryptographically prove it has been following a constitution for months or years. New agents build trust over time, like credit reports. This creates a verifiable reputation system for autonomous agents.
