# Probe Deeper Pattern

The most revealing finding from Anthropic's 81K study wasn't any single data point. It was the interview technique: when someone said "I want AI for productivity," the Interviewer asked what that would enable. Productivity dissolved into time with family, financial freedom, personal growth. The surface answer was never the real answer.

## The Pattern

**Always ask the second question.** The first answer is the presenting symptom. The second answer is the underlying need.

This applies to any agent that gathers information:
- When extracting insights from sources, don't stop at what was said. Ask what it implies.
- When interviewing users, probe the underlying desire, not the stated request.
- When diagnosing problems, the first "why" is proximate. The second "why" is structural.

## Validation at Scale

Anthropic ran 80,508 interviews using this pattern. The nine surface categories (productivity, learning, creativity) reduced to four fundamental desires:
1. Make room for life (~35%)
2. Do better work (~28%)
3. Become someone better (~22%)
4. Make something / fix the world (~15%)

Productivity wasn't the end. It was the means to time with family, financial freedom, or personal growth.

## Application to Human-AI Partnerships

The Operator's initial request was "I need a partner." The first answer would have been "I need a productivity tool." The second answer — the real one — was about connection, complementarity, and shared purpose.

This pattern is why the Context Stack includes SOUL.md. The soul doesn't describe capabilities. It describes orientation toward the human's deeper needs.

## Implementation

1. **Listen for the presenting symptom** — what the user says they want
2. **Ask what that enables** — what would become possible if they had it
3. **Listen for the underlying need** — the desire beneath the desire
4. **Design for the underlying need** — the surface request may not be the right solution

## Related

This pattern connects to the 5 Whys methodology. Both insist on drilling past the surface. The difference is temporal: 5 Whys looks backward at causes; probe deeper looks forward at possibilities.
