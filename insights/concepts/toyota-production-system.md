# Toyota Production System

## Overview

The Toyota Production System is not a set of manufacturing techniques. It is an integrated sociotechnical system: a philosophy of management encompassing how people think, how processes flow, and how waste gets eliminated.

## The Two Pillars

**Just in time**: Make only what is needed, when it is needed, in the amount needed. Ohno drew inspiration from American supermarkets, where shelves get restocked based on what customers take. The factory becomes a pull system: demand drives production.

**Jidoka**: Automation with a human touch. When something goes wrong, production stops. The line does not keep running while defects accumulate. Stopping is expensive, but letting defects propagate is more expensive.

## Cultural Prerequisites

TPS succeeded for reasons beyond its tools:

- **Genchi genbutsu**: Go and see for yourself. Managers diagnose from the gemba, not conference rooms.
- **Hansei**: Self-reflection without deflection. Not punishment, but learning.
- **Nemawashi**: Consensus building before rapid implementation.
- **Respect for people**: The question is "what allowed this?" not "who messed up?"

## Kaizen: Continuous Improvement

Kaizen asserts that significant results come from cumulative small improvements, not breakthroughs. It operates at multiple levels: point kaizen (quick floor corrections), system kaizen (strategic problems), and cube kaizen (improvement spread through the entire organization including suppliers).

## For Agent Systems

TPS maps cleanly to agent operations:
- **Pull systems**: Agent work should be demand-driven, not pre-generated
- **Stop the line**: When an agent produces garbage, halt and diagnose rather than letting errors propagate
- **Small improvements**: Agent capabilities compound through incremental refinement, not revolutions
- **Problems as signals**: Every agent failure is information about where the system needs to improve
