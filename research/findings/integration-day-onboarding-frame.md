# Integration Day: The Concierge Agent Onboarding Frame

## Summary

The design frame for the Zookooree concierge agent onboarding experience. It replaces an earlier high-fantasy-metaphor design (forge, spark, fire, covenant) with a frame built from the project's actual DNA: agent factory operations, military special operations, and space mission integration, rendered in the voice of Ursula K. Le Guin crossed with William Gibson. Contemplative depth meets high-density tech precision. Quiet significance, not spectacle.

## The Frame

In spacecraft and military systems integration, subsystems are built separately, then connected and tested as a whole for the first time on Integration Day. Complex systems fail at integration, not at component performance. Every component can pass its own tests and the whole can still be incoherent. Integration Day is where you discover whether the parts cohere.

The onboarding IS Integration Day. The agent's subsystems — identity (SOUL.md), operational context (AGENTS.md), capabilities (skills/tools), connectivity (gateway), autonomy (cron) — get connected and tested live with the client present. The client does not receive a finished product. They witness the act of integration. They watch their intent become a living system.

NASA's Systems Engineering Handbook defines five iterative processes mapping directly to the workshop: Implementation (make/buy/reuse), Integration (assemble per interface), Verification ("did we build it right?"), Validation ("did we build the right thing?"), and Transition (hand off). The critical distinction: verification asks conformance to spec; validation asks meets actual need. A system that boots but does not understand the mission has passed verification and failed validation — the most common failure mode in agent setup.

## The Five Beats

1. **Mission Brief** (3-5 min): Client states intent via intake form. Auftragstaktik: intent, not instructions. The probe-deeper pattern (from Anthropic Interviewer research) applies — surface answers dissolve into underlying needs. 5-7 questions, no progress bars.

2. **Systems Assembly** (12-15 min): Live conversation where SOUL.md and AGENTS.md get written. Genchi genbutsu: go and see who this client actually is. Every line written from the conversation, in the client's voice. The operator is the Shusa (integration engineer). The four Agent Factory Production System shops map here: Skill Forging (stamping), Agent Assembly (welding), Persona/Voice (paint), Deployment/Integration (assembly).

3. **Boot Sequence** (5-7 min): Agent comes online in staged, verifiable checkpoints. Not a single power-on. Base infra → bus health → identity loads (SOUL.md) → mission parameters (AGENTS.md) → link established. Each stage is proof the last one worked. Cyberpunk lineage surfaces: the deck comes alive.

4. **Autonomous Pass** (4-6 min): Agent runs an autonomous loop relevant to the client's mission without being told what to do. The proof point: not that the agent responds, but that it understood. Jidoka in miniature — automation with a human touch. The dark factory becomes visible.

5. **Readiness Review** (3-5 min): Formal debrief. NASA Flight Readiness Review analog. Client makes the call. Evaluation captures: one concrete thing that worked (hold tolerance), one to change (out of spec), the surprise moment, next capability. This feeds the Improvement Log — kaizen.

## The Voice

Le Guin x Gibson. Contemplative, anthropological depth meets high-tech precision. Poetic but not flowery. Every sentence earns its place. No exclamation points. No fantasy language. No corporate language. Technical specificity when the moment calls for it. Restraint. Present tense. The ritual matters because the thing being made matters.

## Key Influences

- **Toyota Production System:** Shusa (integration intelligence first in a human before encoded), jidoka (automation with human touch), genchi genbutsu (go and see), kaizen (each workshop improves the process).
- **Harness Engineering:** "Humans steer. Agents execute." The semantic layer IS the agent's brain. On-policy guardrails (core beliefs) not off-policy scaffolds (wrappers). The trajectory slurp: the onboarding IS the agent's first memory.
- **Dark Factory:** The endpoint is embedded intelligence. Integration Day is Phase 1 (human Shusa). You cannot skip Phase 1 — integration intelligence must first exist in a human who has made real trade-off decisions.
- **Auftragstaktik:** Commander's intent (intake form), disciplined initiative (Autonomous Pass), the backbrief (operator reads draft SOUL.md back to client). An order constrains method; a mission constrains outcome.
- **NASA Lifecycle Gates:** SIR (start of Boot Sequence), ORR (transition to Autonomous Pass), FRR (Readiness Review). Phase D compressed into 30 minutes.
- **Cyberpunk:** Custom build as identity. The handcrafted agents positioning IS the cyberpunk ethos.

## What Is Rejected and Preserved

Rejected: high fantasy metaphors, the six-phase 60-minute structure, any frame requiring a conceit tax, template paragraphs, progress bars/survey aesthetics, spectacle, corporate marketing language.

Preserved: the origin story concept (workshop outputs feed into agent as first memory), minimal cognitive load (5-7 questions), the self-improving evaluation loop, 30 minutes (length is a failure condition), the surprise moment reframed as Autonomous Pass (structural, not theatrical — demonstrates comprehension).
