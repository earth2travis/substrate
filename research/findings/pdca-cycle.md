# PDCA: The Scientific Method in Organizational Clothing

## Summary

PDCA (Plan-Do-Check-Act) is the iterative improvement cycle that underlies lean manufacturing, Agile software development, and AI agent operations. It is the scientific method adapted for organizational use.

## Origins

- Walter Shewhart (Bell Labs, 1920s–30s): statistical process control, three-step cycle
- W. Edwards Deming (1940s–50s): expanded to four steps, taught in Japan
- Japanese JUSE participants compressed it to: Plan, Do, Check, Act
- Toyota adopted PDCA as core discipline

Deming preferred PDSA (Study over Check): "Study" implies learning, not just pass/fail inspection.

## The Four Phases

| Phase | Activity | Key Discipline |
|-------|----------|----------------|
| **Plan** | Identify problem, root cause, hypothesis | Grasp current condition; make predictions |
| **Do** | Implement change on limited scale | Execution as experiment, not deployment |
| **Check** | Compare results to predictions | Study, don't just check; be willing to be wrong |
| **Act** | Standardize success or revise hypothesis | Close the loop; open the next one |

## Software Parallels

- **Agile sprints** — Plan work, build it, review in retrospective, adjust next sprint
- **CI/CD** — Each code change is a small experiment; failed builds trigger investigation
- **Feature flags / A/B testing** — Controlled experiments with measured hypotheses
- **Postmortems** — Retrospective PDCA applied to failure

## AI Agent Operations

- **Prompt engineering** — Each revision is a PDCA cycle with documented experiments
- **Behavior tuning** — Plan behavioral hypothesis, implement, evaluate, standardize
- **Memory management** — Iterate on storage/retrieval strategies with measured outcomes
- **Human-AI collaboration** — Propose new division of labor, trial it, evaluate, adjust

## Key Insight

PDCA's power comes from the speed and frequency of the cycle, not formality. A team running a tight PDCA loop daily outperforms one running a meticulous cycle quarterly. Speed of learning is the competitive advantage.
