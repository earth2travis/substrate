# From Toyota to The Agent Factory

Toyota does not build cars; Toyota builds the system that builds cars. The Agent Factory does not build agents; it builds the system that builds agents. Toyota's 40-year factory planning arc maps directly onto agent production system design.

## Key Points

**Phase 1: Strategic decision and site selection.** Toyota evaluates total cost of operations over decades, not just upfront costs. Agent Factory equivalent: selecting runtime (OpenClaw, Claude Code), knowledge stores (GitHub, Obsidian), and coordination layers (Loom, MCP) that can expand from 3 agents to 300 without rebuild.

**Phase 2: Factory design and layout engineering.** The four shops of agent production:
1. Skill Forging (Stamping): raw capabilities shaped into portable SKILL.md files
2. Agent Assembly (Welding): skills, memory, identity, and tools welded into functioning agents
3. Persona and Voice (Paint): SOUL.md and behavioral tuning that make generic agents specific
4. Deployment and Integration (Assembly): connections to messaging, GitHub, cron, other agents

**Phase 3: Construction.** Scope expansion during construction is the norm. The NC battery plant went from $1.3B to $13.9B. Design the first version to be expandable; get one production line running end-to-end before adding others.

**Phase 4: Trial production.** The most important phase. A pilot team builds agents by hand, documents everything, and develops standardized processes. Cardboard engineering (mocking up SOUL.md and workflows before implementation). Multiple rounds of trial production with real tools, each better than the last.

**Phase 5: Start of production and ramp-up.** Andon cord becomes kill switch + escalation. Visual controls become dashboards. Pull system becomes demand-driven agent creation. Continuous improvement becomes lesson extraction and skill optimization.

**Phase 6: Continuous investment and evolution.** Toyota's factories receive investment for decades. The Agent Factory can go further: agents run their own lesson extractors, optimize their own skills, identify gaps, and monitor their own health. Jidoka (automation with human touch) is more achievable in software than in steel.

**Agent Factory Production System (AFPS).** Two pillars: Just-in-Time Agent Production (build when needed, composed from modular skills) and Jidoka (autonomous operation with self-detected error escalation). Seven wastes translated: overproduction (agents nobody asked for), waiting (blocked on missing skills), transport (unnecessary data movement), overprocessing (work that doesn't change output), inventory (stale context), motion (redundant tool calls), defects (wrong outputs, hallucinations).

## Relevance

The factory is the product. The agents are proof that the factory works.
