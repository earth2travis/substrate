# Agent Company Research: Recommended Actions

## Summary

Three low-effort, high-value actions from analyzing multi-agent company articles.

## Recommended Actions

**1. Adopt Memory Type Taxonomy in MEMORY.md**
- Insights: new discoveries, observations
- Patterns: recurring behaviors, trends
- Strategies: what works, approaches
- Preferences: user and agent preferences
- Lessons: what we learned from mistakes

Effort: 30 minutes. Impact: structured retrieval instead of linear scanning.

**2. Add Priority Tags to Key Memories**
- Critical (decisions, commitments, blockers)
- Notable (insights, context worth remembering)
- Background (nice to know, low urgency)

Effort: 15 minutes. Impact: load critical first when context is limited.

**3. Verify ClawVault Before Considering**
Research task: does the repo exist? Is the npm package real and maintained? Can benchmark claims be reproduced?

Effort: 1 hour. Impact: validates or eliminates a candidate memory architecture.

## What NOT To Do

- Don't add more agents. One agent working well beats five agents in coordination overhead.
- Don't adopt the full closed-loop state machine. Complexity without clear benefit.
- Don't trust unverified benchmark claims without independent reproduction.
