# Ryan Lopopolo: Pioneer of Harness Engineering

## Summary

OpenAI Frontier team member who pioneered harness engineering: a methodology where 0 lines of code were written by humans for a 1M+ line codebase. Author of the viral "Harness Engineering" article (February 2026).

## Background

- Member of Technical Staff, OpenAI Frontier (Bellevue, WA)
- Previous: Snowflake, Brick, Stripe, Citadel
- First podcast appearance: discussing harness engineering topics

## Work

- Built OpenAI's internal Symphony orchestrator
- Developed dark factory approach: no human-written code
- Team grew from 3 to 7 engineers while throughput increased
- Uses Codex extensively with 1-week horizon for sub-minute task completion

## Philosophy

- "Don't put agents in a box" — give agents full accessibility over their domain
- Human review should be post-merge, not pre-merge
- Code as context: docs, tests, review agents inject non-functional requirements
- Everything is prompts: what the agent can't see is garbage
