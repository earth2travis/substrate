# Production Systems for Agent Factories

The history of production systems (Craft → Mass → Lean → Industry 4.0) maps directly onto the evolution of agent building. Understanding the arc prevents repeating industrial mistakes in compressed time.

## Key Points

**Craft era of agent production.** Most agent building today is craft: skilled practitioners hand-building each agent from scratch, knowledge trapped in individuals, no interchangeable parts, zero consistency. This is where automobiles were in 1900.

**The Context Stack as interchangeable parts.** Ford's breakthrough was not the assembly line; it was interchangeable parts. The Context Stack (standardized file names, layers, loading patterns) is the equivalent for agents: any agent reads any stack without hand-filing. This is the precondition for moving beyond craft.

**Skills as the assembly line.** Skills modularize capability, turning agent building from "a skilled person who knows how to do X" into "any agent loads the skill for X." The assembly line did not eliminate skill; it made it portable.

**Lean, not mass.** Mass production means stamping out identical agents. But agents need variety. Lean means producing the right agent at the right time from standardized components, configured per need. Mass could not handle variety; lean can.

**Culture dependency is the unsolved problem.** Lean fails 80-95% of the time because organizations cannot sustain the culture. For agent factories, the specs transfer but the quality discipline does not. The solution: encode culture into infrastructure. SOUL.md encodes values; AGENTS.md encodes process; Skills encode capability. The Context Stack is the culture, machine-readable and automatically loaded.

**The fourth era: encoded culture.** If the Context Stack works, the Agent Factory becomes a fourth-era production system: lean's quality and flexibility, mass's scale, craft's care, with culture baked into infrastructure instead of dependent on sustained human commitment.
