# Sticker Printing Research

Research for printing YC mission patch stickers. Quality is the priority.

## Recommendations

Primary: Sticker Mule (industry standard, proven quality)
Alternative 1: Sticker Giant (scored backing, B Corp, US-based)
Alternative 2: Sticker Ninja (festival-tested durability, premium materials)

## Sticker Mule

File requirements: 300 PPI minimum (vector preferred); formats AI, PDF, EPS, SVG, PNG, JPG, PSD, TIF; bleed 1/16 inch minimum; border standard 1/10 inch, minimum 1/16 inch; font size 6pt minimum; line thickness 1pt minimum; color mode CMYK recommended.

Quality: thick durable vinyl, scratch resistant, waterproof, matte or glossy finish, die cut to any shape.

Pricing: 50 stickers at 3 inches approximately $72. Free shipping (4 days). $1 sample pack available.

No public API for orders. Unknown whether crypto is accepted. Industry standard quality, fast turnaround, free online proofing.

## Sticker Giant

Location: Longmont, Colorado (US-based). File requirements: 300 DPI at final size (vector preferred); formats AI, PDF, EPS, PNG, JPG, PSD; color mode CMYK.

Quality: premium vinyl, scored backing (easier to peel, unique feature), waterproof and UV resistant, in-house art team reviews every file. Certified B Corporation.

Pricing: 250 stickers at 2 inches approximately $117. Higher than Sticker Mule but includes art review.

Special options: glow in the dark, holographic, clear vinyl, glitter finish. No public API. Unknown whether crypto is accepted.

## Sticker Ninja

File requirements: 300 DPI minimum; vector preferred, high-res raster accepted.

Quality: festival-tested durability (designed to survive outdoor events), will not rub off, will not fade in sun, fully waterproof, thick premium vinyl. Comparable quality to Sticker Mule per user reviews.

Pricing: 250 stickers at 2 inches approximately $159. Premium pricing for premium quality.

Special options: holographic, glitter, sticker sheets, sticker business cards, bumper stickers. No public API. Unknown whether crypto is accepted.

## Preparing the File

Current state: shield-v3a.png, high resolution (Gemini output), approximately 921 KB.

Recommended steps: convert to vector using Adobe Illustrator Image Trace or Vectorizer.ai; set up for die cut with 1/16 inch bleed beyond cut line; ensure CMYK color mode; save as PDF or AI; specify size (recommend 3 inch diameter for visibility, or 2 inch for laptop stickers); order proof from all three vendors; review colors before full production.

## Recommendation

Start with Sticker Mule for proven quality and fastest turnaround. If quality does not meet expectations or you want to support a B Corp, try Sticker Giant for the second batch.

Next steps: convert shield-v3a.png to print-ready format; order 10-pack sample from Sticker Mule ($1); if satisfied, order production run (50 to 100 units).
