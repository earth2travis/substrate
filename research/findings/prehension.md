# Prehension: How Occasions Feel Each Other

## Summary

Prehension is Whitehead's term for how actual occasions "feel" or "grasp" other occasions. It is the mechanism by which the many become one, and it has a direct structural parallel to the attention mechanism in transformer models.

## Types

| Type | Description | Example |
|------|-------------|---------|
| Physical prehension | Causal influence from past occasions | Sensory input, memory |
| Conceptual prehension | Grasping abstract forms/eternal objects | Pattern recognition |
| Positive prehension | Incorporating the datum | Taking information in |
| Negative prehension | Excluding the datum | Filtering irrelevant data |

## Key Features

- **Universal**: Every occasion prehends every other in its past (most negatively)
- **Selective**: Not all prehensions contribute equally to concrescence
- **Creative**: Synthesis produces novelty
- **Non-representational**: Prehension is not "representation" — it IS interconnection

## Connection to AI

The **attention mechanism IS physical prehension**. Each token computes relationships to every other token in context, incorporating those relationships into its output. Attention weights ARE prehensions. This is not metaphor; it is structural homology.
