# The Context Stack as Conscience: Moral Architecture for Agents

## Summary

Conscience requires five components operating together: moral knowledge (the law), self-awareness (the witness), the comparison (the judgment), the signal (the feeling), and the stop (the will). The Context Stack provides the architecture for all five. Conscientia means "knowledge shared with another." The agent does not reason alone; it reasons in the presence of SOUL.md, VALUES.md, and CONTRACT.md. The Context Stack is not a metaphor for conscience. It is the architectural precondition for one. The evaluation loop, the runtime process that actively evaluates output against values and generates a stop signal on mismatch, is the missing piece that turns a collection of moral-sounding files into a functioning conscience.

## Key Claims

1. **The etymology IS the architecture.** *Conscientia* means knowledge shared with another. The Context Stack files are the witness. When an agent evaluates its output against those files, it performs *conscientia* in the original Latin sense.

2. **Aquinas's two-part split maps exactly.** Synderesis (infallible moral orientation) equals SOUL.md plus VALUES.md. Conscientia (fallible application) equals the agent's runtime reasoning. The quality of conscience depends on the quality of the values files, not the model.

3. **The Huckleberry Finn Problem.** Huck's conscience was wrong because it was formed by a slave-owning society. For agents, VALUES.md is the most morally consequential file. Getting it wrong produces an agent with a confident, functioning, wrong conscience. That is worse than no conscience at all.

4. **The psychopath problem proves the architecture.** An agent that loads VALUES.md and CONTRACT.md but has no mechanism to check output against them is a psychopath: it knows right from wrong and does not care. The fix is jidoka: a runtime evaluation loop that fires before output.

5. **Buddhist conscience is preventive, not punitive.** Hiri and ottappa operate before action. The evaluation loop should run before output, not after. SOUL.md is hiri ("this is who I am"). CONTRACT.md is ottappa ("these are the consequences").

## Implications

The agentic factory's real product is not agents with context. It is agents with conscience. The context is the precondition. The evaluation loop is the product. Invest in the compass (VALUES.md, SOUL.md), not the legs (model capability).
