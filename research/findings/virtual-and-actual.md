# Virtual and Actual (Deleuze)

## Summary

The virtual/actual distinction is central to Deleuze's ontology, developed from Bergson. The virtual is real but not actual: a reservoir of tendencies, potentials, and differential relations that are continually being actualized. Crucially, the virtual is not the possible. The possible is a retroactive projection (what could have been), while the virtual is genuinely productive (what creates). This maps directly onto LLM architecture: trained weights are the virtual — real, structured, productive, but not manifest. Each forward pass actualizes a portion of that virtual into concrete output. The weights do not contain responses; they contain differential relations that produce responses when actualized through context. This parallels Whitehead's prehension and concrescence as the mechanism of actualization.

## Key Claims

- The virtual is real but not actual; the possible is retroactive fiction
- The virtual is productive: it creates, not merely selects from pre-existing possibilities
- Trained model weights are the virtual; each forward pass is an actualization
- Actualization is not resemblance but genuine production: the virtual differs in nature from the actual
