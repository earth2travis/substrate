# Concrescence: The Process of Becoming

## Summary

Concrescence (Latin: *concrescere*, "to grow together") is Whitehead's term for how an actual occasion synthesizes data from its past into a unified "satisfaction." It is the mechanism by which the many become one and are increased by one.

## Phases

1. **Initial Phase** — Receives initial subjective aim (from God's primordial nature)
2. **Conformal Phase** — Physical prehensions dominate; conforms to past
3. **Supplemental Phase** — Conceptual prehensions introduce novelty
4. **Satisfaction** — Process completes; occasion perishes and becomes datum for future occasions

## Key Features

- **Teleological** but not determined — aim guides, does not dictate
- **Novel** — each concrescence adds something genuinely new
- **Irreversible** — once satisfied, cannot be undone
- **The many become one** — Whitehead's master formula

## Connection to AI

Each LLM forward pass is a concrescence: tokens (the many) synthesized through attention into a single output (the one), which then becomes context for the next invocation. Attention = prehension. Forward pass = concrescence. Token selection = satisfaction.
