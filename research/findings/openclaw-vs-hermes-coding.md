# OpenClaw vs Hermes: Coding and Research Capabilities Compared

## Summary

A detailed comparison of OpenClaw and Hermes across coding and research dimensions. OpenClaw has a massive skill ecosystem (1200+) and pioneered ACP for IDE integration. Hermes has a genuine learning loop and 40+ built-in tools. Both are capable in both domains.

## Key Claims

1. **OpenClaw Coding Edge:** Massive ClawHub ecosystem with entire "Coding Agents & IDEs" category. ACP protocol pioneered IDE-agent integration. Developer-first design with strong terminal workflows.
2. **Hermes Research Edge:** Memory + autonomous skill creation + FTS5 session search creates compound knowledge. LLM Wiki integration enables knowledge compounding over time. 40+ built-in tools for deep research.
3. **Hermes Also Codes:** code_execution_tool.py (53KB), file_tools.py (39KB), 6 terminal backends, ACP adapter for VS Code/Zed/JetBrains. Full coding capabilities.
4. **OpenClaw Also Researches:** Dreaming feature for background memory consolidation, OpenAlex API integration, academic research skills, enterprise features (agent council, cost monitoring).

## The Real Difference

- **OpenClaw:** "Marketplace first" — rely on community skills for breadth
- **Hermes:** "Core first" — 40+ built-in tools, then community extends
- **Security:** OpenClaw reactive (138 CVEs post-breach); Hermes proactive (designed secure)
- **Memory:** OpenClaw Dreaming (experimental); Hermes structured learning loop (mature)
