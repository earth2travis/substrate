# DevOps

## Summary

DevOps is a culture and set of practices that combines software development (Dev) and IT operations (Ops) to shorten the development lifecycle and deliver features, fixes, and updates in close alignment with business objectives. DevOps shares lean manufacturing's emphasis on flow, feedback loops, and continuous improvement. The DORA metrics (deployment frequency, lead time, change failure rate, restore time) originated from DevOps research and are the primary quantitative measures of software delivery performance. Key practices include infrastructure as code, continuous integration and continuous delivery, monitoring and observability, automated testing, and collaboration between development and operations. In the context of agent systems, DevOps is the operational layer that enables autonomous deployment: agents write code, the DevOps pipeline validates, deploys, and monitors it.

## Key Claims

- DevOps is a culture, not a tool — the goal is breaking down silos between Dev and Ops
- The DORA metrics provide quantitative measures of software delivery performance
- DevOps IS lean for software: it eliminates handoffs, improves flow, and builds in quality
- In dark-factory environments, DevOps pipelines become the autonomous nervous system
