# Rhizome (Deleuze & Guattari)

## Summary

The rhizome is Deleuze and Guattari's model for non-hierarchical, non-arborescent structures, introduced in *A Thousand Plateaus* (1980). Unlike trees with their roots, trunks, and hierarchical branches, rhizomes connect any point to any other point. Grass, fungi, and the internet are rhizomatic. The five principles are connection, heterogeneity, multiplicity, asignifying rupture, and cartography. The LLM Wiki pattern and knowledge graphs are rhizomatic: no single root or hierarchy, cross-references form from any concept to any other. Multi-agent systems also operate rhizomatically, forming ad-hoc connections rather than following rigid hierarchies. GitHub issues, PRs, and commits form a rhizomatic "living project graph" where the graph emerges from work, not top-down design.

## Key Claims

- Rhizomes connect any point to any other; trees enforce hierarchy from root to branch
- Principles: connection, heterogeneity, multiplicity, asignifying rupture, cartography
- Rhizomes map rather than reproduce: no deep structure to copy
- Knowledge graphs, multi-agent systems, and GitHub workflows are rhizomatic structures
