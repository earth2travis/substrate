# Obeya (Big Room)

## Summary

Obeya (大部屋, literally "big room") is a visual management system used at Toyota where all key stakeholders gather in a shared space with visual displays of project status, challenges, and milestones. It is the physical manifestation of the Shusa's integration role: visual displays cover the walls, cross-functional representatives attend regular meetings, and the goal is rapid decision-making rather than information reporting. The Shusa leads the meetings and makes trade-off decisions on the spot. Obeya supports just-in-time by making the current state visible to everyone simultaneously, reducing delays from information asymmetry. It enables kaizen by making problems visible and actionable. Modern equivalents include war rooms, incident bridges, and digital dashboards. For agent systems, the Obeya maps to shared observability dashboards showing all agent product states in real time.

## Key Claims

- Obeya makes the complete state of a program visible to everyone simultaneously
- It reduces information asymmetry and enables rapid, informed decision-making
- The Shusa uses Obeya to amplify integration without formal authority
- Modern software equivalents (war rooms, dashboards) serve the same function digitally
