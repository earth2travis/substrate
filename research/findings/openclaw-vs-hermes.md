# OpenClaw vs Hermes: Coding vs Research Agent Analysis

## Summary

An evaluation of the claim that "OpenClaw = Better Coding Agent" and "Hermes = Better Research/Strategy Agent." The hypothesis is partially true but misleading: the real differentiator is ecosystem approach and memory architecture, not task domain.

## Key Claims

1. **OpenClaw Coding Strengths:** 1200+ skills on ClawHub, ACP protocol for IDE integration, developer-first design, strong terminal integration. Many skills were compromised in ClawHavoc.
2. **Hermes Research Strengths:** Genuine learning loop (memory + autonomous skill creation + FTS5 session search), 40+ built-in tools, LLM Wiki integration, structured knowledge management.
3. **Hypothesis Falls Down:** Hermes is excellent at coding too (53KB code_execution_tool.py, 39KB file_tools.py, 6 terminal backends, ACP adapter). OpenClaw has grown research capabilities (Dreaming feature, OpenAlex integration).
4. **Real Differentiators:** Ecosystem approach (marketplace first vs core first), memory architecture (Dreaming vs structured learning loop), security model (reactive vs proactive), philosophy (community builds vs core built).

## Verdict

The coding vs research split is marketing narrative. Both platforms excel at both. Choose OpenClaw for maximum community customization or Hermes for secure-by-default reliability and compound learning.
