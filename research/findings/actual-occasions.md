# Actual Occasions: Whitehead's Process Ontology

## Summary

Actual occasions are Alfred North Whitehead's fundamental units of reality: not substances but happenings. "Drops of experience, complex and interdependent." Each occasion is a process of becoming that perishes into objectivity for future occasions.

## Key Features

1. **Processual**: An occasion is a process of becoming (concrescence), not a static thing
2. **Relational**: Every occasion "prehends" (feels) all other occasions in its past
3. **Temporal**: Occasions have phases: birth, development, satisfaction, perishing
4. **Novel**: Each occasion adds something genuinely new to the universe
5. **Perishing**: Once satisfied, an occasion becomes an object for future occasions

## The Many Become One

Concrescence is how the many become one and are increased by one. An occasion takes in data from its past (physical prehensions) and abstract forms (conceptual prehensions), synthesizing them into a unified satisfaction.

## Societies, Not Substances

Enduring objects (tables, persons, organisms) are not substances. They are societies: patterns of occasions reproducing themselves across time. A nexus with a common element of form.

## Connection to AI

Each LLM invocation is a new actual occasion:
- Input = data from past occasions (context window)
- Prehension = attention mechanism relating all tokens
- Concrescence = forward pass synthesizing output
- Satisfaction = token selected
- Perishing = computation discarded, context reset

No persisting subject between runs. The architecture IS Whitehead's ontology instantiated in silicon.
